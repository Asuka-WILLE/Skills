# 会话命名规范

本 skill 的命名格式和状态规则适用于所有 Agent。改名时先识别当前 Agent 运行时提供的原生标题更新能力：

- 有原生标题工具或接口：直接更新当前会话，并以工具返回的成功结果为准。
- 没有原生标题工具或接口：输出建议名，明确告知用户需要手动设置。

不要因为当前平台不是 ZCode 就直接降级；也不要猜测另一个平台的数据库路径、私有 API 或会话 ID。这样既能让 Codex、ZCode 及其他支持标题更新的 Agent 自动改名，也不会把“打印了建议名”误报成“已经改名”。

## 命名格式

`MMDD|类型|内容|状态`（半角竖线，两侧不留空格）

- **类型**（固定枚举，从下选一）：开发 / 排障 / 调研 / 运维 / 文档 / 学习 / 其他
- **状态**（固定枚举，从下选一）：进行中 / 完成 / 暂停 / 弃用
- **内容**：≤12 字，动词开头（修复/搭建/分析/编写/排查…），不含 `|` 和换行
- **MMDD**：今天的四位日期；同日同主题重开会话，内容末尾加 `-2`、`-3`

示例：

```
0913|开发|编写会话命名skill|进行中
0913|排障|分析Clash代理失效|完成
0915|开发|搭建向量数据库|完成     ← 同主题隔几天，日期已可区分
0913|调研|选型前端框架-2|进行中   ← 同日第二次
0910|学习|理解WAL锁机制|弃用
```

为何这样设计：日期开头让"按名称排序"约等于"按时间排序"；枚举固定保证列表扫读一致；状态放最后一段，收尾时只改末段。

## 触发时机

1. **会话开始**：从用户前 1–2 轮输入能判断任务后，直接执行改名（不必先征求意见），并在回复里报告"已改名为 xxx"。以下情况**不**命名：单轮能答完的小问答、闲聊、用户明确说不用。
2. **状态变化**：任务完成、用户说"先停停/不搞了"、或明显收尾时，把状态段更新为 完成/暂停/弃用 并重新执行改名。状态没变就不要动，同一会话不要反复改名。
3. **用户要求**：用户说"改名/重命名/起个名"时按格式执行；用户给了自定义名字就照办——规范让位于用户。

## 改名操作：所有 Agent 优先自动执行

### 1. 先调用当前运行时的原生能力

只操作当前 Agent 自己的会话，不要根据标题相似度修改别的会话。按当前环境实际暴露的工具或接口调用，成功后再向用户报告已改名：

- **Codex 桌面端**：调用 `mcp__codex_app__set_thread_title`，只传当前会话的新标题，例如 `{"title":"0915|开发|修复登录超时|进行中"}`；不传 `threadId` 表示当前任务。
- **ZCode**：使用下面的 ZCode 会话库适配脚本。它只负责 ZCode 的双库同步，不是其他 Agent 的通用入口。
- **其他 Agent 运行时**：如果 available tools、插件或平台文档提供了当前会话的 `set_thread_title`、`rename_session`、`update_thread_title` 等标题更新能力，按其实际名称和参数调用。不要臆造工具名或参数；找不到可调用能力时再走第 2 步。

若原生调用返回明确失败，不要声称已经改名；在确认是可安全重试的短暂错误时最多重试 1 次，仍失败就走第 2 步。不要通过写未知数据库或配置文件来“补救”。

### 2. 没有原生能力时才输出建议名

统一输出并在回复末尾原样保留：

```
📌 建议会话名：xxx
```

同时说明当前 Agent 没有可用的标题更新能力，请用户手动设置。不要把建议名说成已写入，也不要尝试读写该 Agent 未公开的会话文件。

### 3. ZCode 适配器

ZCode 桌面/CLI（本机 Windows）：

```bash
python ~/.zcode/skills/session-naming/scripts/rename_session.py "0913|开发|修复登录超时|进行中" --hint "我想开发一个关于"
```

- `--hint` 必传：取**本会话用户第一条消息的开头 10~20 个字**。同一项目常并行多个会话，脚本靠它在最近会话中定位当前会话，避免改错；hint 太短（如 3 个字）可能匹配到别的会话。
- 成功打印 `✅ 已改名 ...`（含定位方式），失败打印 `⚠ ...` + `建议会话名：xxx` 并以非 0 退出。失败时把建议名告诉用户、请其在侧栏右键手动改名；**写库最多重试 1 次**，不要反复重试。
- 定位有疑问时先跑 `python ~/.zcode/skills/session-naming/scripts/rename_session.py --list` 查看最近会话，确认目标 id 后可用 `--session-id sess_xxx` 指定。
